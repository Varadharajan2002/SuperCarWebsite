# SuperCarWebsite (Next.js)

Responsive car showcase website built with **Next.js**, React, and the original HTML/CSS design.

## Live Site
[https://mynext-car.web.app/](https://mynext-car.web.app/)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
```

Creates a static export in `out/` for Firebase Hosting.

```bash
firebase deploy
```

## Features
- Next.js App Router with static export
- Swiper car carousel
- Brand filters for featured cars
- Scroll reveal animations
- Background video gallery
- Remix icons and original styling
